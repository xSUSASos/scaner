# Сканер на iPhone — как установить

Нужен iOS 16.4 или новее.

## Вариант 1 (рекомендуется): веб-приложение (PWA)

1. Откройте на iPhone в **Safari**: https://xsusasos.github.io/scaner/
2. Нажмите **Поделиться** (квадрат со стрелкой) → **«На экран Домой»** → **Добавить**.
3. Запускайте с иконки на рабочем столе — откроется на весь экран, как обычное приложение.

Плюсы: бесплатно, без Apple ID и без срока действия, обновляется само. После первого
запуска работает без интернета (фото никуда не отправляются — всё обрабатывается на телефоне).

## Вариант 2: нативное приложение без Mac (Windows + бесплатный Apple ID)

Нужно, если хочется «настоящее» приложение (системное меню «Поделиться», сохранение в Файлы).

1. Скачайте `Scaner-unsigned.ipa` со страницы релизов:
   https://github.com/xSUSASos/scaner/releases (файл в разделе *Assets*).
2. На Windows установите **iTunes с сайта Apple** (https://www.apple.com/itunes/ →
   «Windows» → загрузить с сайта), **не из Microsoft Store** — нужны драйверы для iPhone.
   Если iCloud для Windows установлен из Microsoft Store — тоже лучше поставить версию с сайта Apple.
3. Установите **Sideloadly** (https://sideloadly.io) — или **AltStore** (https://altstore.io, там же AltServer).
4. Подключите iPhone кабелем, разблокируйте, нажмите «Доверять этому компьютеру».
5. **Sideloadly:** перетащите `.ipa` в окно, в поле *Apple account* введите свой Apple ID → **Start**,
   введите пароль (и код 2FA, если спросит).
   **AltStore:** значок AltServer в трее → *Install AltStore* на iPhone, затем в AltStore
   на телефоне: *My Apps* → «+» → выберите `.ipa` (файл нужно заранее положить на iPhone, например в Файлы).
6. На iPhone:
   - **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → **Доверять**.
   - **Настройки → Конфиденциальность и безопасность → Режим разработчика** → включить,
     телефон перезагрузится, после перезагрузки подтвердите «Включить».
     (Пункт появляется только после первой установки такого приложения.)

**Ограничения бесплатного Apple ID:**
- подпись действует **7 дней**, потом приложение перестаёт запускаться — переустановите
  (данные внутри сохраняются). AltStore продлевает автоматически по Wi-Fi, если на компьютере
  запущен AltServer и компьютер с телефоном в одной сети;
- одновременно не больше **3** таких приложений (включая сам AltStore).

**Честно о рисках:** Sideloadly и AltStore — неофициальные программы, вы вводите в них пароль
Apple ID (они передают его только Apple для получения сертификата разработчика). Если сомневаетесь —
заведите **отдельный Apple ID** специально для этого.

## Вариант 3: App Store / TestFlight

Только с платной подпиской **Apple Developer Program** ($99 в год). Понадобится:
- сертификат распространения (Distribution certificate) и provisioning profile для
  `io.github.xsusasos.scaner`;
- запись приложения в **App Store Connect**, скриншоты, описание, политика конфиденциальности;
- для App Store — ревью Apple (TestFlight для внешних тестировщиков — упрощённое ревью).

Mac для этого не обязателен: подписанную сборку можно делать в GitHub Actions
(fastlane `match` для сертификатов + App Store Connect API key для загрузки). Сейчас это не настроено.

## Для разработчика

Сборка `.ipa` — автоматически в GitHub Actions (`.github/workflows/ios.yml`): поставьте тег
`mobile-vX.Y.Z` (или запустите вручную во вкладке Actions) — готовый файл появится в релизе
этого тега или в *Artifacts* запуска.

Открыть проект в Xcode (нужен Mac с Xcode 26+):

```sh
cd mobile
npm ci
npm run vendor      # OpenCV, Tesseract и др. в vendor/
npm run cap:sync    # сборка www/ и копирование в ios/
npx cap open ios    # откроет ios/App/App.xcodeproj
```

Иконка и заставка iOS генерируются скриптом (на Windows, нужен Pillow из десктопного venv):
`..\.venv\Scripts\python.exe scripts\make_ios_icon.py`.
